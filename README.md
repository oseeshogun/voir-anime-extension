# Voir Anime - Historique

Extension de navigateur qui garde l'historique des épisodes regardés sur voir-anime.to.
Les données restent dans ton navigateur (stockage local), rien n'est envoyé ailleurs.

## Installation (Chrome, Edge, Brave)

1. Décompresse le fichier zip.
2. Ouvre `chrome://extensions` (ou `edge://extensions`).
3. Active le « Mode développeur ».
4. Clique sur « Charger l'extension non empaquetée » et choisis le dossier décompressé.
5. Ouvre un épisode sur voir-anime.to, puis clique sur l'icône de l'extension pour voir l'historique.
